I build with **Python and FastAPI**, connecting language models to tools, databases, and interfaces. My projects explore **AI agents**, **retrieval-augmented generation (RAG)**, and **voice workflows**.

Along the way, I'm working on the pieces that make these applications useful: persistent conversations, authentication, document retrieval, and streamed responses.

- 💾 Checkpoints saved in PostgreSQL for multi-turn memory
- 🔐 Email verification + JWT auth + web interface
